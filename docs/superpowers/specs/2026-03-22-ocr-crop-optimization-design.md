# OCR 裁剪优化设计文档

**日期：** 2026-03-22
**主题：** 优化 main.py 中的 OCR 识别功能，添加图片裁剪预处理

## 背景

当前 main.py 中的 OCR 识别功能对完整图片进行识别，效果不够理想。需要优化：先将图片从中间裁剪为左右两半，然后从左半图片的右下角裁剪出四分之一区域，从右半图片的左下角裁剪出四分之一区域，最后对这两个裁剪区域进行 OCR 识别。

## 目标

- 提高 OCR 识别准确率，特别是底部表格区域的文字（编号、颜色、版次、目数、日期等）
- 保持现有代码结构，最小化改动
- 添加调试支持，方便验证裁剪效果

## 设计方案

### 1. 整体架构

修改 `main.py`，添加新的裁剪函数，修改 `ocr_extract_text()` 来使用裁剪预处理。

### 2. 新增函数

#### `crop_bottom_table_regions(img, debug=False, debug_dir='debug_crop')`

从图片中裁剪出左右底部的表格区域。

**输入：**
- `img`: PIL Image 对象 - 原始图片
- `debug`: bool - 是否保存调试图片
- `debug_dir`: str - 调试图片保存目录

**输出：**
- `dict`: `{'left': left_table_img, 'right': right_table_img}` - 左右表格区域的 PIL Image 对象

**实现步骤：**
1. 从中间切分图片为左右两半
   - 计算中线：`mid_x = width // 2`
   - 左半：`(0, 0, mid_x, height)`
   - 右半：`(mid_x, 0, width, height)`

2. 对每一半，取四分之一区域作为候选区域
   - 候选区域大小：宽 = 半图宽度 // 2，高 = 半图高度 // 4
   - **左半图片：** 取右下角的四分之一区域
     - `x = 左半宽度 - 候选区域宽度`
     - `y = 左半高度 - 候选区域高度`
     - 候选区域：`(x, y, 左半宽度, 左半高度)`
   - **右半图片：** 取左下角的四分之一区域
     - `x = 0`
     - `y = 右半高度 - 候选区域高度`
     - 候选区域：`(0, y, 候选区域宽度, 右半高度)`

3. 在候选区域内精确定位表格
   - 转换为灰度图
   - 检测黑色区域边界（寻找从黑到白或白到黑的过渡）
   - 确定表格的上下左右边界
   - 裁剪时留少量边距（左右 10px，上下 5px）

4. 如果 `debug=True`，保存裁剪后的图片

#### 辅助内部函数 `_find_table_bounds(region_img)`

在候选区域内找到表格的精确边界。

**输入：** `region_img` - 候选区域 PIL Image
**输出：** `(x1, y1, x2, y2)` - 表格边界坐标

### 3. 修改 `ocr_extract_text(png_file_path, debug=False)`

**修改内容：**
- 添加 `debug` 参数（默认 `False`）
- 在 OCR 之前先进行裁剪

**新流程：**
1. 打开图片 `img = Image.open(png_file_path)`
2. 调用 `crop_bottom_table_regions(img, debug=debug)` 获取左右表格
3. 对左表格和右表格分别进行 OCR 识别
   - 复用现有的多预处理、多配置、评分逻辑
   - 创建一个内部辅助函数 `_ocr_single_region(region_img)` 来处理单个区域
4. 合并两个表格的识别结果，用 `"\n---\n"` 或类似分隔符分隔
5. 返回合并后的文字

**错误处理：**
- 如果裁剪返回的图片为空或裁剪失败，回退到原始的全图识别方法
- 保持现有异常处理不变

### 4. 调试支持

- 当 `debug=True` 时：
  - 保存裁剪后的左右表格图片到 `debug_crop/` 文件夹
  - 文件名格式：`{base_name}_left_table.png`, `{base_name}_right_table.png`
  - 打印裁剪区域坐标信息

### 5. 保持不变的部分

- `cdr_to_png()` - 不修改
- `write_to_excel()` - 不修改
- `main()` - 不修改（调用 `ocr_extract_text()` 时不传 `debug` 参数，默认关闭）
